# 날짜 수정·백엔드 연결 구현 결과

확인일: 2026-11-05. 사용자 요청에 따라 디자인 작업은 별도 담당으로 두고 날짜 계산과 새 화면 연결을 준비했다.

## 완료한 변경

같은 현지 날짜의 기록이 UTC 자정을 기준으로 서로 다른 날로 계산되던 문제를 수정했다. 이력의 timestamp와 명시적 ZoneId에서 날짜·요일·분을 계산한다. Android와 PC 호출부도 새 규격을 사용한다. [세부 정책](02_날짜시간대_수정.md).

화면과 핵심 로직 사이에 DemoBackend와 불변 상태 DTO를 추가했다. 새 웹 화면에서 호출할 수 있도록 127.0.0.1 전용 API, JavaScript 클라이언트, TypeScript 선언, 예시 응답, 실행·검증 스크립트를 제공한다. 추천과 교통 비교 알고리즘은 기존 Java core 한 곳에 유지한다.

빈 기록의 추천 결과 처리에서 발견한 null 목적지 오류도 수정했다. 입력 오류, 정보 없음, 저장 오류, 주행 상태, 중복 요청을 화면에서 구분할 수 있다. 같은 이동에 대한 안내 요청을 한 번으로 제한하고 응답 유실 시 자동 재전송하지 않는다.

합계 숫자로 제품 완성률을 산정하지 않는다. 핵심·서비스·HTTP 검사는 서로 다른 계층의 회귀 검사이며 실제 차량 검증을 대신하지 않는다. PC 검사는 기존 Swing 버튼 이벤트와 파일 렌더 검사이고 새 디자인의 시각 품질 검사가 아니다.

Android 빌드에는 기존 SDK XML 버전 차이와 deprecated API 경고가 남았으나 빌드는 성공했다. APK를 에뮬레이터나 차량에 설치·실행하지 않았다. 로컬 HTTP 검사는 실제 소켓 권한이 있는 실행 환경에서 수행했다. 검사 때 시작한 백엔드 프로세스는 모두 종료했다.

## 현재 판단과 남은 한계

**새 화면에 연결해 조작 가능한 프로토타입을 만드는 데 필요한 백엔드는 준비됐다.** 실제 차량 연동의 구현 가능 여부는 여전히 정상 Pleos 환경에서 확인해야 한다.

로컬 API의 교통과 안내는 모의 응답이다. 실시간 교통, 실차 경로 안내, 지도 경로 도형, 경로 성향별 ETA, 휴대폰 동기화, 앱 미실행 중 상시 학습은 제공하지 않는다. 기존 순정 내비 ANR·지도 표시 문제와 경유지 A/B/C 시험은 이번 작업에서 재검증하지 않았다. 통과한 것으로 바꾸지 않았다.

접수용 시연에 활용할 수 있는 기술 기반은 있지만 출품 규정 적합성, 새 화면 완성도, 실차 성공을 이 결과만으로 확정할 수 없다. 수집 해제 저장에 실패한 경우 현재 실행은 중지하지만 디스크의 이전 동의값은 남을 수 있다는 한계도 연결 계약에 명시했다.

## 재사용과 출처

기존 `04_ROUTINE_PROTOTYPE_20261104`의 코드·빌드 설정을 작업 복사본으로 재사용했다. 기존 02 경유지 프로젝트, 04 프로토타입, 05 인수인계 문서를 수정하지 않았다. 05 폴더에는 v2를 가리키는 새 안내만 추가했다. SDK·시스템 이미지·캐시·실행별 연결 토큰은 전달본에 포함하지 않는다.

날짜 API와 HTTP 서버 API 의미를 확인할 때만 공식 문서를 보완했다. 확인일 2026-11-05: [Java Instant](https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/time/Instant.html), [JDK HttpServer](https://docs.oracle.com/en/java/javase/17/docs/api/jdk.httpserver/com/sun/net/httpserver/HttpServer.html).
