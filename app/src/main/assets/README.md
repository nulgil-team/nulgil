# 글꼴 출처

AstaSans-Variable.ttf는 Claude 웹 사양의 assets 파일을 변경 없이 재사용했다.

- 프로젝트: Asta Sans, https://github.com/42dot/Asta-Sans
- 직접 재사용한 기준: frontend 커밋 `3f2cc4763fcde1dc365b5d9ddd3c68131978a11e`의 `frontend/assets/AstaSans-Variable.ttf`
- 라이선스: 같은 폴더의 OFL.txt, SIL Open Font License 1.1
- 복사·확인: 2026-11-05, 글꼴과 라이선스 각각 원본과 SHA-256 일치 확인
- 사용: 늘길 Android 차량 화면의 한글·숫자·버튼. 폰트 이름과 파일 내용은 변경하지 않음

Android 기기에서 실제 글꼴 렌더·행 높이·한글 잘림은 SDK 연결 후 검수한다.
