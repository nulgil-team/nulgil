# 늘길 · 들를 곳 초대 웹 (친구용)

운전자의 차 화면에 보이는 QR이나 6자리 코드로 열리는 페이지입니다. 친구가 들를 곳을 검색해 보내면, 차량 앱에서 운전자가 정차 중에 확인하고 경로에 넣습니다. 빌드 도구 없이 정적 파일로 배포합니다.

## 파일 구성 (디자인 수정 위치)

| 파일 | 역할 | 언제 고치나 |
|---|---|---|
| `styles/tokens.css` | 색, 글꼴, 글자 크기, 간격, 모서리, 그림자, 다크 모드 | 전체 분위기를 바꿀 때. 다른 CSS는 이 변수만 씁니다 |
| `styles/components.css` | 카드, 입력창, 버튼, 장소 목록, 상태 배지, 지도 상자 | 부품 모양을 바꿀 때 |
| `styles/base.css` | 페이지 폭, 제목, 기본 글자 | 레이아웃 틀 |
| `src/views.js` | 화면별 HTML(코드 입력, 장소 고르기, 확인, 보낸 뒤 상태)과 문구 | 문구·배치를 바꿀 때 |
| `src/app.js` | 화면 흐름과 상태 | 흐름을 바꿀 때 |
| `src/api.js` | 서버(Supabase RPC) 호출 | 서버 함수가 바뀔 때 |
| `src/places.js` | 장소 검색(OpenStreetMap Nominatim) | 카카오·네이버 검색 등으로 교체할 때. `{ name, address, latitude, longitude }`만 돌려주면 됩니다 |
| `src/map.js` | 확인 화면 지도(Leaflet, OpenStreetMap 타일) | 지도를 바꿀 때 |
| `src/config.js` | 서버 주소, 공개 키, 상태 확인 주기 | 서버를 옮길 때 |

화면 템플릿은 버튼과 입력에 `data-action`, `data-field` 속성만 붙이고, 동작은 `app.js`가 이 속성으로 찾습니다. 마크업을 새로 짜도 이 속성만 유지하면 됩니다.

## 실행

모듈 스크립트라 파일을 직접 열면 동작하지 않습니다. 정적 서버로 엽니다.

```
npx serve invite-web
```

`/?c=ABC234`처럼 코드를 주소에 붙이면 코드 입력 화면을 건너뜁니다.

## 차 앱과 상태

차(늘길 0.5)의 `친구에게 들를 곳 받기`가 코드를 만들고 10초마다 제안을 읽습니다. 친구 화면의 상태는 차가 서버에 쓴 값입니다.

| 상태 | 뜻 |
|---|---|
| `PENDING` | 운전자가 아직 확인하지 않음(정차 확인 등으로 보내지 못했을 때도 되돌아옴) |
| `REQUESTED` | 순정 내비에 경로 추가를 요청함 |
| `ADDED` | 순정 재조회로 경로에 들어간 것을 확인함 |
| `UNCONFIRMED` | 요청했지만 반영을 확인하지 못함(다시 요청하지 않음) |
| `DISMISSED` | 운전자가 이번엔 넘김 |

차 화면의 배치와 문구는 `app/src/main/java/kr/routine/app/ui/InvitePanel.java`(지도는 `RouteMapCard.java`), 서버 주소와 이 페이지 주소는 `app/src/main/res/values/invite.xml`에 있습니다.

## 서버와 개인정보

- 서버 구조: `../server/supabase/migrations/` (처음 구조 `20261121000000_invite_stops.sql`, 상태 되돌리기 `20261121010000_invite_not_sent.sql`)
- 서버에는 친구가 고른 장소(이름·주소·좌표), 보낸 사람 이름, 한마디, 짧은 이동 코드만 저장합니다. 차량의 위치·목적지·경로는 보내지 않습니다.
- 초대 코드는 12시간 뒤 만료되고, 한 이동에 제안은 10곳까지입니다.
- 시제품 한계: 누구나 초대를 만들 수 있고 요청 수 제한이 없습니다(스팸 방지 미구현).
- 장소 검색어는 OpenStreetMap Nominatim으로 전송됩니다(이용 정책상 1초에 1번 이하, 자동완성 없음).
