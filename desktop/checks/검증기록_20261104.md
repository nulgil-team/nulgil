# PC 시연앱 검증 기록

2026-11-04. Java 22로 Java 17 대상 코드를 컴파일하고, headless Swing 환경에서 실제 버튼 처리기를 EDT로 실행했다. 원래 현대차 프로젝트는 수정하지 않았다.

## 결과

- `runs/20261104_02/ui-check.txt`: **25개 검사 통과**, 프로세스 종료 코드 0.
- 공유 core와 데스크톱 소스 전체의 `javac --release 17` 컴파일 통과.
- 창을 띄우는 수동 사용 시험은 하지 않았다. 테스트는 Swing 컴포넌트의 `doClick()`·값 변경·재생성을 사용했다.
- 1차 실행은 교통 정보 누락의 표시 문구를 검사하는 단정에서 멈췄다. 모의 어댑터가 실패 콜백을 반환하는 계약에 맞춰 단정을 수정했고, 새 실행 폴더에서 다시 검사했다. 1차 기록은 보존했다.

## 확인한 동작

빈 저장소의 요청 금지, 예시 이력 저장 전 동의, 3개의 서로 다른 날짜에서 목적지 추천, 정체 44분과 과거 예상 중앙값 29분의 비교, 정보 누락 시 ETA 미표시, 주행 상태에서 확인 비활성, 넘기기 시 요청 없음, 확인 한 번에 요청 한 번, 중복 클릭 차단, 완료 후 조건 변경 차단, 재시작 후 선택 이력·선호 유지, 다른 요일·시간대의 추천 보류, 기록 삭제 후 직접 등록한 규칙 유지, 수집 중지 시 기록하지 않음, 실패 요청의 재시도 차단·학습 제외를 확인했다.

## 화면 확인

`runs/20261104_02/evidence`의 1200×800 PNG는 실제 Swing 패널을 렌더한 결과다. 합성 지도나 실제 차량 화면이 아니다.

- `01_congestion.png`: 모의 정체와 평소 대비 지연.
- `02_missing_traffic.png`: 교통 정보 조회 실패.
- `03_confirmed.png`: 모의 안내 확인 및 중복 요청 비활성.
- `04_unconfirmed.png`: 요청 결과 미확인 및 재요청 차단.

한글 표시, 목적지·지연 설명·버튼·프로토타입 표시의 잘림과 겹침을 확인했다. 작은 창 크기 전체, 다른 운영체제·폰트, 실제 Android 화면은 검증하지 않았다.

## 실행 연결

진입점은 `kr.routine.desktop.DesktopApp`이다. `--data <파일 경로>`를 받으며 지정하지 않으면 실행 작업 폴더의 `demo-data/desktop.properties`를 사용한다. 기존 데이터가 손상됐으면 저장소 오류를 표시한다. 시연은 항상 모의 교통과 공개 예시 장소를 사용하며 순정 내비를 변경하지 않는다.

자동 검사 진입점은 `kr.routine.desktop.DesktopUiCheck <새 증거 폴더>`다. core 소스, `desktop/src/main/java`, `desktop/checks/DesktopUiCheck.java`를 함께 컴파일한다. 이미 사용한 증거 폴더는 재사용하지 않는다.
